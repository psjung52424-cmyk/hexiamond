# Hexiamond Arena

육각형 보드 위에 삼각형 블록을 놓아 줄을 지우는 퍼즐 게임.
테트리스에서 출발했지만 **중력이 없고**, 대신 라인이 **세 방향**으로 생깁니다.

의존성 없는 단일 HTML 파일입니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 규칙

- 정육각형 보드를 정삼각형 96칸으로 타일링합니다 (한 변 4).
- 조각은 삼각형 2~4개로 이루어진 **폴리아이아몬드**. 방향은 스폰될 때 랜덤으로 정해지고 **회전할 수 없습니다.**
- 조각은 보드 어디에나 놓을 수 있습니다. 쌓이지 않고, 떨어지지 않습니다.
- 한 줄이 꽉 차면 소멸합니다. 줄은 **가로 / ↗ / ↘** 세 축에 각각 8줄씩, 총 24줄입니다.
- 놓을 곳이 없으면 게임 종료.

한 칸에 마우스를 올리면 그 자리에 놓았을 때 완성되는 줄이 해당 축의 색으로 미리 표시됩니다.

## 점수

| 항목 | 계산 |
|---|---|
| 배치 | 놓은 삼각형 수 |
| 라인 소멸 | `지워진 칸 수 × 10 × 동시배수 × 콤보배수` |
| 동시배수 | 1줄 ×1, 2줄 ×3, 3줄 ×6, 4줄 ×10, 5줄 ×15 |
| 콤보배수 | 연속으로 지울 때마다 `1 + 0.3 × (콤보−1)` |

여러 줄을 한 번에 지우는 쪽이 압도적으로 유리합니다.

## 타임랩스

게임이 끝나면 `타임랩스` 버튼으로 그 판을 처음부터 재생할 수 있습니다.
배치 순서·점수·소멸한 줄을 기보로 저장해 두고, 판의 길이와 무관하게 약 11초에 들어오도록
한 수당 간격을 자동 조절합니다.

## 좌표계

삼각 격자를 `(r, g)` 로 다룹니다. `r` 은 행, `g` 는 행 안에서의 전역 열이고,
**위를 향한 삼각형 ⟺ `(r + g)` 가 홀수** 입니다.

세 라인 축의 밴드 인덱스는 다음과 같습니다.

```
A = r                  (가로)
B = ⌊(g − r) / 2⌋      (↗)
C = ⌈(g + r) / 2⌉      (↘)
```

한 변 `N` 인 육각형에서 세 축 모두 `2N` 개의 밴드를 가지며,
각 밴드의 길이는 `2(N+d)+1` (`d` = 중앙으로부터의 거리) 로 세 축이 완전히 대칭입니다.
`N = 4` 이면 `9 · 11 · 13 · 15 · 15 · 13 · 11 · 9`, 합 96칸.

조각의 60° 회전은 각 삼각형을 세 꼭짓점으로 분해해 육각 격자에서
`R(i, j) = (−j, i + j)` 로 회전시킨 뒤 다시 삼각형으로 복원하는 방식으로 계산합니다.
평행이동은 `(dr + dg)` 가 짝수일 때만 삼각형의 방향이 보존되므로, 정규화할 때 이 패리티를 맞춰 줍니다.

## GitHub Pages 로 배포하기

파일이 `index.html` 하나뿐이라 별도 빌드가 필요 없습니다.

1. 저장소 → **Settings** → **Pages**
2. Source 를 `Deploy from a branch`, 브랜치를 `main` / `root` 로 지정
3. 잠시 뒤 `https://<사용자명>.github.io/hexiamond/` 에서 열립니다

## 저장 데이터

최고 점수는 브라우저의 `localStorage` 에 `hexiamond.best` 키로 저장됩니다.
서버로 전송되는 데이터는 없습니다.
